# allenatoreritmo
un allenatore per riconoscere e leggere sequenze ritmiche in tempi semplici dalla semibreve alla croma
L’app è divisa in tre blocchi, tutti funzionanti come allenamento o gioco: nel primo si propone una sequenza ritmica da ripetere ad orecchio, si può anche vedere la parte scritta per facilitare il compito, nella seconda si deve realizzare un ritmo dato in tempo reale, nella terza viene proposta una sequenza ritmica e l’allievo deve scegliere la notazione corretta tra le tre proposte.
